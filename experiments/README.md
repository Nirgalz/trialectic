# Explorations graphiques et adaptateurs trIA

Le projet ne maintient qu'une seule carte Cytoscape de référence :
[applications/triad-graph](../applications/triad-graph/).

Les expérimentations peuvent créer des producteurs de données, des adaptateurs
de protocoles, des scénarios et des essais d'interaction, **sans cloner le
moteur graphique**. Une proposition retenue est intégrée dans la référence
après validation explicite de l'auteur; le code devenu redondant est supprimé.
Les tests restent ciblés sur des risques concrets pendant cette phase
exploratoire. Voir [docs/ui-reference.md](../docs/ui-reference.md).
