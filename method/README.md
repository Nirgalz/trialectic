# Method / Méthode trialectique

This directory marks the **conceptual Method** boundary independently of the
trIA application and of any specific JSON representation.

**Current canonical source:** [Trialectic Method working reference](../reference/trialectic-method.md).
The path `reference/trialectic-method.md` is intentionally retained for now:
existing AI instructions, MCP resources, documentation and release/history links
depend on its complete content. Relocation requires its **own** complete
compatibility migration, not a copied competing definition.

Conceptual author approvals and their history remain in [DECISIONS.md](../DECISIONS.md).
The existing [French](../docs/fr/presentation.md) and
[English](../docs/en/overview.md) explanations remain derivative learning material.
The [bilingual conceptual glossary](../terminology/french-english-glossary.md)
documents translations with explicit validation status.

**Out of scope:** JSON schema field names, PowerEvaluation serialization,
application prompt composition, Cytoscape UI and human-facing label choices.
See [Formalization](../formalization/README.md), the
[interface glossary](../terminology/analyst-interface-glossary.md), and
[architecture plan](../docs/separation-of-concerns.md).
